Sudoku encoding
256 cells → normalized vector
What's happening: Each cell of the 16×16 sudoku (values 1–16) is divided by 16 to produce a number in (0, 1]. This gives us a 256-element vector that acts as a high-entropy seed. Because every row, column, and 4×4 box contains each value exactly once, no two valid sudokus produce the same vector.

Chaos parameter derivation
vector → (x₀, μ)
What's happening: Two running sums condense the 256-value vector into two parameters. x₀ (initial condition) is the mean. μ (growth rate) uses a position-weighted sum so the ordering of cells matters — not just the values. μ is clamped just below 4.0 to stay in the strongly chaotic regime.

Logistic map iteration
x_(n+1) = μ · x_n · (1 − x_n)
What's happening: Starting from x₀, the logistic map is iterated thousands of times. For μ ≥ 3.57 the orbit becomes chaotic — visiting (0, 1) in a deterministic but unpredictable pattern. The first 1000 iterations are discarded as warmup. The Lyapunov exponent being positive proves true chaos: nearby starting points diverge exponentially.

Keystream extraction
float orbit → uint8 bytes
What's happening: Each chaotic value xₙ is multiplied by 10¹⁴ — this lifts the most-chaotic low-order digits into the integer range — then taken mod 256 to fit in a single byte. The result is a uniformly-distributed pseudo-random byte sequence. Mean should be ≈ 127.5 and standard deviation ≈ 73.9 (theoretical optimum).
Quantization
key[i] = floor(xᵢ × 10¹⁴) mod 256
Multiplying by 10¹⁴ exposes the low-order chaotic digits. The mod 256 maps each result to a byte. This makes the keystream extremely sensitive — even a 10⁻¹⁵ change in xₙ can flip a key byte.

5
XOR pixel encryption
pixel ⊕ key → cipher
What's happening: Each pixel byte is XOR-ed with one byte of the keystream. XOR is involutive — applying it twice with the same key gives back the original. Low PSNR (≈8 dB) means encryption is strong. The cipher's Shannon entropy approaches 8.0 bits/byte, the theoretical maximum, meaning the cipher looks like uniform random noise.
